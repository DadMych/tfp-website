# Accessibility

All web and product design we deliver targets WCAG 2.2 level AA: colour contrast, focus states, text sizes and touch target sizes are checked before handoff.

## Accessibility audit

An accessibility audit of an existing website or app costs €1,200 as an add-on to any plan. It covers up to 10 screens and produces a list of issues ranked by severity, each with a suggested design fix. It is a design review: it does not include testing with assistive-technology users or checking your code.

## What we can't promise

Accessibility depends on how the design is built. We hand off annotated designs, but we don't write the code, so we can't certify that a finished site is compliant.
