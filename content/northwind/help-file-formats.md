# File formats we deliver

We hand over design files, not a production codebase. The formats below are the ones you can expect in a delivery. If a vendor asks for something else, tell us while the request is open. We will not invent a format at the end because a printer emailed you the night before launch.

## Logos and icons

Logos are delivered as SVG, PNG and PDF.

- SVG is the one to use wherever the mark has to scale: product UI, a website, any layout that changes size.
- PNG is there for tools that refuse SVG.
- PDF is there for people placing the logo in a document who should not be redrawing it.

Icons are delivered as SVG. We do not also wrap every icon as a PNG and a PDF. If a specific icon has to land in a document that cannot take SVG, say so on the request and we will export that one.

Do not trace a logo or an icon back out of a presentation. Use the file we delivered.

## Fonts are not in the folder

Brand fonts are not included in the files. You license them yourself. The delivery can name the family. It will not contain the font files. Licensing is covered in its own article; the short version is that a folder of exports is not a font licence.

## Source

You also get the Figma source for the work. That file is where the screens, components and decisions actually live. Exports are copies for people who should not be editing the source. Access to Figma follows the access rules for your plan, and it does not last forever after an engagement ends.

## The logo animation

When the work includes a simple logo animation, we deliver it as MP4 and as Lottie JSON. MP4 plays anywhere you can drop a video. Lottie is the JSON file a product can run as animation without embedding a video.

That is the extent of video we do. We do not deliver longer films, explainers, or motion packages beyond that simple logo animation. If you need those, they are not hiding in the handoff under another extension.
